Return the transpose of a rectangular matrix: output row c contains the input values at column c.

Implement `Solution.Transpose(int[][] matrix)`. Input has 1..20 rows, each with the same 1..20 columns, and values in -1000..1000. Preserve all values; do not change the input. A non-square matrix must also work.

## Examples

Input: `[[1, 2, 3], [4, 5, 6]]` → output: `[[1, 4], [2, 5], [3, 6]]`.
Input: `[[7]]` → output: `[[7]]`.
