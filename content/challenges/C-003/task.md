Return the length of the longest contiguous run of equal integers.

Implement `int longest_run(const int *values, size_t count)`. Empty input returns 0. Values are between -10000 and 10000; there are at most 200 values. Do not change the input.

## Examples

Input: `[4, 4, 2, 2, 2, 4]` → output: `3`.
Input: `[]` → output: `0`.
