Return all even integers followed by all odd integers, preserving their original order within each group.

Implement `evensFirst(array $values): array`. Zero and negative even integers are even. Return a JSON list with consecutive indices, including for empty input. At most 200 integers in -10000..10000. Do not sort either group.

## Examples

Input: `[3, 2, 1, 4]` → output: `[2, 4, 3, 1]`.
Input: `[]` → output: `[]`.
