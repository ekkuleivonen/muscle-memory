Multiply two polynomials represented by coefficient lists, lowest power first.

Implement `multiply(a, b)`. For example [2,3] means 2 + 3x. Each input has 1..20 integer coefficients in -100..100. Return exactly a.length + b.length - 1 coefficients, including trailing zeros. Do not change either input.

## Examples

Input: `[[1, 2], [3, 4]]` → output: `[3, 10, 8]`.
Input: `[[0], [2, 3]]` → output: `[0, 0]`.
