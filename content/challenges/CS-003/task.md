Return the length of the longest contiguous strictly increasing stretch.

Implement `Solution.Longest(int[] values)`. Equal neighbors break a stretch. Empty input returns 0. There are at most 200 integers in -10000..10000; the input must stay unchanged.

## Examples

Input: `[1, 3, 2, 4, 6]` → output: `3`.
Input: `[2, 2, 2]` → output: `1`.
