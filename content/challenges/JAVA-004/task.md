Return the sum of both diagonals of a square matrix, counting the center only once.

Implement `Solution.diagonalSum(int[][] matrix)`. For row r, diagonal columns are r and n-1-r. Input has n rows of n integers, with 1 <= n <= 20 and values in -1000..1000. Do not change the matrix.

## Examples

Input: `[[1, 2, 3], [4, 5, 6], [7, 8, 9]]` → output: `25`.
Input: `[[7]]` → output: `7`.
