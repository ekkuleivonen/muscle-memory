Return the greatest common divisor of all input integers as a nonnegative integer.

Implement `int common_divisor(const int *values, size_t count)`. Ignore signs. The result for an empty list or an all-zero list is 0; gcd(0, n) is abs(n). At most 100 integers, each in -10000..10000.

## Examples

Input: `[18, 24, 30]` → output: `6`.
Input: `[0, -12, 18]` → output: `6`.
