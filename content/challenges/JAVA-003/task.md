Return the first index whose value is at least target, or the array length if no such value exists.

Implement `Solution.lowerBound(int[] values, int target)`. The input is sorted ascending and can contain duplicates. Empty input returns 0. At most 200 integers in -10000..10000; target has the same range. Do not change the array. Any correct search strategy is accepted.

## Examples

Input: `[[1, 3, 3, 7], 3]` → output: `1`.
Input: `[[1, 3], 9]` → output: `2`.
